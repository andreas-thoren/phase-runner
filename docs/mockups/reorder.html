POST payload

The whole resulting order is sent in one request — not a “move X to Y” instruction. The server checks that this set of pks is exactly the set it holds for this macrocycle, then renumbers 1..N in a single transaction.

What this mock-up is demonstrating

  • Tap-to-select / tap-to-place instead of drag — identical on mouse, touch and keyboard, no library.
  • Microcycles can land in a different mesocycle; drop markers appear in every group.
  • Mesocycles reorder with buttons, which stays usable at phone width.
  • Every date shift is shown inline (was …), and rows overlapping dates already trained are called out in the banner — the “allow it, but make it visible” option.
  • Moving every microcycle out of a mesocycle leaves it empty and zero-length, shown explicitly.
  • Total plan length never changes — only the internal boundaries move.
